First working 3D avatar module: a real-time rendered 3D character whose mouth follows the uploaded narration audio.

Open-source MIT avatar engine

The avatar and lip-sync model run in your browser. First load needs internet to download the 3D model and small lip-sync model. Current release animates the face (mouth, brows and blinks); it is not yet the custom semi-realistic Zeeroz cartoon teacher and does not include hand/body gestures or subject demonstrations.

Make the teacher speak

This module uses the actual audio to animate mouth shapes; it does not fake lip movement from text. The current open-source character is a starter avatar. The custom Zeeroz teacher character, full-body actions and animated science diagrams are still under development. No paid voice API is called.

Current capability and next integration

3D model rendering and audio-driven lip-sync are handled by an open-source browser SDK. The next connection is automatic Urdu/Sindhi lesson narration generation and then combining the speaking avatar with animated subject demonstrations in the lesson video exporter.

No API key, paid avatar credits, or Firebase billing is required for the 3D avatar module. Natural Urdu/Sindhi voice generation is a separate component and is not claimed as complete here.
