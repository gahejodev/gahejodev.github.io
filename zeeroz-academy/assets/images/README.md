# Zeeroz Academy Image Library

Store optimized, educational images used by course lessons here.

## Folder convention
- biology/class-9 through biology/class-12
- chemistry/class-9 through chemistry/class-12
- physics/class-9 through physics/class-12
- mathematics/class-9 through mathematics/class-12
- computer-science/class-9 through computer-science/class-12
- teaching-licence/

## Image standards
- Prefer WebP; use SVG for clean, original vector diagrams when appropriate.
- Use descriptive lowercase kebab-case filenames.
- Optimize for mobile; avoid unnecessarily large files.
- Add meaningful alt text and a short caption in lesson content.
- Use original or properly licensed educational artwork only.
- Never store student personal data or confidential material.

## Lesson syntax
Use a relative path from the Zeeroz Academy pages, for example:

![Animal cell structure](assets/images/biology/class-9/animal-cell.webp)

The public deployment workflow copies this directory with the rest of the Academy website.
