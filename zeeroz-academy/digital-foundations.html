Module 01 · Lesson 01

What is a computer system?

A computer is an electronic device that accepts data, processes it according to instructions, stores information and produces results. A computer system includes physical equipment, programs, data and the people who use it.

1. Hardware — the physical parts

Hardware means the physical components of a computer or digital device. Examples include a keyboard, screen, processor, camera, memory chip and storage drive.

2. Software — the instructions

Software is the set of programs and instructions that tell hardware what to do. An operating system manages the device; applications help users perform tasks such as writing, browsing or editing photos.

3. The information cycle

StageMeaningExample
InputData enters the systemTyping with a keyboard
ProcessingInstructions work on dataCalculating a total
OutputResults are presentedShowing an answer on screen
StorageData is saved for laterSaving a file to a drive

4. Common device categories

  • Input: keyboard, mouse, touchscreen, microphone, scanner and camera.
  • Output: monitor, printer, speakers and projector.
  • Processing: CPU executes instructions; a GPU handles many graphics and parallel-computing tasks.
  • Storage: SSD, hard drive, memory card and USB drive retain files. RAM is temporary working memory, not long-term file storage.

5. RAM and storage are different

RAM temporarily holds information the device is actively using and is generally cleared when power is turned off. Storage keeps files and applications after the device is switched off. More RAM can help multitasking; more storage gives room for files and apps.
